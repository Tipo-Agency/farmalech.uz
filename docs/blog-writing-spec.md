# Правила статей блога farmalech.uz

Сайт: farmalech.uz, производитель БАД ООО «AF FARMALECH» (Ташкент, Узбекистан). Аудитория: покупатели в Узбекистане, родители, женщины, мужчины 35+, а также фармацевты.
Данные о товарах брать ТОЛЬКО из `lib/products.tsx` и `lib/new-products.tsx` (состав, форма, способ применения, противопоказания). Чего там нет, о товаре не писать.

## Файл
`content/blog/ru/<slug>.md`, slug из `docs/content-plan.md`. Формат строго такой:

```
---
title: Заголовок из плана (можно уточнить, до 70 знаков)
description: Мета-описание 120–160 знаков, без точки в конце не обязательно, без кавычек-ёлочек в начале
date: 2026-11-18
category: Рубрика из плана
products: altex, altex-syrup
keywords: ключ 1, ключ 2, ключ 3, ключ 4
---

Вводный абзац 2–4 предложения: о чём статья и кому полезна.

## Подзаголовок H2
Текст…

### Подзаголовок H3
Текст…

- пункт списка
- пункт списка

## Частые вопросы

### Вопрос 1?
Ответ 2–4 предложения.

### Вопрос 2?
Ответ.

### Вопрос 3?
Ответ.
```

Поддерживаемая разметка (свой простой парсер, ничего другого не использовать): `## `, `### `, абзацы через пустую строку, списки `- ` и `1. `, `**жирный**`, ссылки `[текст](/products/slug)` и `[текст](/blog/slug)`. Без таблиц, без HTML, без картинок, без `#` H1 (H1 берётся из title), без эмодзи.

## Содержание
- Объём тела 3000–6000 знаков с пробелами (цель ~4000–4500). 4–7 разделов H2, где уместно H3. Последний раздел H2 строго «## Частые вопросы» с 3–5 вопросами (каждый вопрос — H3, заканчивается «?»).
- Ссылки: на 1–3 товара из колонки «товары» вида `[Altex (сироп)](/products/altex-syrup)`, с осмысленным текстом, в теле статьи (не только в FAQ). Ещё 1–3 ссылки на другие статьи плана `/blog/<slug>` по близкой теме (только существующие в плане slug).
- Раздел про товар — спокойный: «в составе [товар] есть X», «это БАД, не лекарство», способ приёма — только как на карточке, со ссылкой «подробнее в карточке». Никаких «лечит», «излечивает», «гарантирует», «вылечит», «эффективен против болезни», «100%». Можно: «поддерживает», «помогает обеспечить поступление», «используют как дополнительный источник».
- Обязательно говорить, когда нужно к врачу (тревожные признаки). Не давать дозировок лекарственных препаратов, не назначать лечение, не советовать отменять лекарства.
- Нельзя выдумывать: исследования, цифры эффективности, проценты, ссылки на «учёные доказали», статистику по Узбекистану, отзывы, сертификаты, награды. Общепринятые справочные факты (например, что железо лучше усваивается с витамином C, что чай снижает усвоение негемового железа) — можно, формулировать осторожно, без цифр, в которых не уверен.
- Медицинский дисклеймер в конце добавит шаблон сайта, отдельный раздел-дисклеймер НЕ писать. Но в тексте уместно напоминать «перед приёмом проконсультируйтесь с врачом», особенно для детей, беременных, кормящих, хронических болезней.
- Стиль: живой, понятный русский, на «вы», без канцелярита и воды, без штампов «в современном мире», «не секрет, что», «важно отметить». Короткие абзацы. Заголовки без точки в конце. Каждая статья уникальна, не повторять одни и те же абзацы между статьями.
- Буква «ё» по возможности. Кавычки «ёлочки». Тире «—».
